使用說明

    
寫好 SQL 按 ▶ 執行，左下方的「執行計畫」會依照 SQL 實際的執行順序列出每個步驟
      （FROM → JOIN → WHERE → GROUP BY → HAVING → 視窗函數 → SELECT → DISTINCT → ORDER BY → LIMIT），
      右邊的舞台會用動畫逐列呈現每一步的中間結果。

    
斷點

    
    
      
  • 行斷點：點編輯器左側的行號（或把游標放在該行按 F9）。有藍色短線的行代表有對應的步驟。
    • 
      
  • 步驟斷點：點執行計畫中每一步前面的小圓點。
    • 
      
  • 播放到有斷點的步驟時，會在「執行該步驟之前」暫停；接著可以按 ↧ 下一列 一列一列看。
    • 
    

    
快捷鍵

    

      
Ctrl+Enter執行（重新計算並從頭播放）

      
F5繼續 / 暫停

      
F10下一步

      
F8下一列

      
F9在游標所在行切換斷點

    

    
顏色

    
    
      
  • 綠色 ✓：條件為 TRUE，保留；紅色 ✗：FALSE，丟棄；黃色 ?：NULL（未知），也會被丟棄。
    • 
      
  • 淡黃底：目前這一列是由哪些來源列產生的（暫停時滑鼠移到任一列也會顯示）。
    • 
      
  • 左側色條：同一組 / 同一個分區。
    • 
    

    
試跑模式開啟時，每次執行都在資料庫的副本上進行，INSERT / UPDATE / DELETE / CREATE 不會保留。
      關閉後，修改會真的寫入目前的資料庫。
